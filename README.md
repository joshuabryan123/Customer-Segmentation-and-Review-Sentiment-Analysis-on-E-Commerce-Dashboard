## 📊 Tableau Interactive Dashboard
• Processed over 99k Brazilian e-commerce transaction records using R and Python, applying K-Means clustering for customer segmentation and a lexicon-based model (OpLexicon) to categorize reviews into positive, negative, and neutral sentiments.</br>
• Translated raw multi-table relational data into actionable recommendations to evaluate delivery performance, assess product quality based on feedback, and identify buyer preferences for strategic decision-making.</br>
• Developed dynamic filters, KPI summaries, and data storytelling components to communicate insights effectively to non-techincal audiences.
